# 💥 爆仓模拟器

一款**戒赌主题**的 A 股模拟网页小游戏。不靠说教戒赌——让你亲手爆仓一次。

## 玩法

开局 10 万元虚拟资金，在 30 个交易日内操作 8 大 A 股板块（银行红利 / AI 算力 / 新能源 / 医药 / 白酒消费 / 券商 / 地产 / 军工）。活到最后，或者爆仓出局。

### 核心机制

- **跷跷板资金池**：全市场热钱总量固定，在板块间流动。热度见顶的板块随时"拥挤出清"——你追的热点，永远是别人出货的出口
- **上头值**：亏钱就上头，上头解锁"配资公司"和"网贷广告"。😤≥50 开配资，≥80 弹出网贷
- **🏦 场外配资公司**：1:2 / 1:5 / 1:10 杠杆。警戒线追加保证金、平仓线强制平仓；跌停封死卖不出去会**穿仓倒欠**。第一次配资老板会故意让你赢（养鱼）
- **A 股特色规则**：T+1（今天买明天才能卖）、涨跌停（跌停卖不出去）、每笔 0.1% 手续费（频繁交易=稳定失血）、银行红利每 10 天发股息
- **小道消息**：70% 是庄家出货的坑
- **复盘三线图**：结算时对比「你的资金曲线 / 躺平线 / 空仓线」，看看你输给了谁

### 种子挑战

开局可输入**行情种子**——同一串种子=同一盘行情。把种子发给朋友，比谁 30 天后剩得多，输的请奶茶 🧋

## 怎么玩

- 在线玩（GitHub Pages）：`https://zhongj1n.github.io/BaoCang-Simulator/`
- 本地玩：直接用浏览器打开 `index.html` 即可，无需联网、无需安装

## 技术

单个 HTML 文件（HTML + 原生 JS + Canvas），零依赖。行情由可播种随机数生成（mulberry32 + Box-Muller 正态分布），每日涨跌 = 隐藏趋势 μ + σ×Z。
